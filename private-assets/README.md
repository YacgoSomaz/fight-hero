# 私有提取与实验工作区

本目录是 `4399-90433-25.swf` 的私有、可审计提取工作区，供后续 AI 复核和继续迁移。它不是浏览器运行时依赖；运行时只读取 `public/assets/`。

仓库只版本化本目录根层的小型研究包（脚本、JSON、截图和本说明）；`extracted/` 是约 3.2 GiB 的本机完整导出，不纳入 Git。

## 保留内容

- `extracted/sprites/`：FFDec 的完整 Sprite 导出；相同像素的连续帧仍保留，因为帧号是时间轴语义的一部分。此目录只保留本地。
- `extracted/images/`：原始位图导出；`extracted/scripts/`：重建 AS3；以及关键声音和地图候选。
- 根目录的 `*.mjs` / `*.py`：提取和显示列表解析工具；`*.json`：时间轴、地图节点与被拒绝方案的实验记录；`*.png`：对齐、碰撞、枪口和动画的人工复核截图。

## 去重规则

只删除逐文件 SHA-256 与权威副本完全一致、且属于第二次整棵 Sprite/声音/SWF 导出的文件。绝不按图像内容删除同一 MovieClip 中的重复帧，也不删除不同实验阶段的截图或 JSON；这些文件对还原 Flash 的播放顺序与排错过程有意义。

权威原始样本、浏览器运行时资源与深度代码包分别在 `assets/reverse/`、`public/assets/` 和 `assets/reverse/ffdec-deep-20260720/`。
